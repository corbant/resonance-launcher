Resonance Launcher Setup

Configure API keys to enable rich movie metadata, backdrop art, and direct deep-linking into your streaming apps.

TMDb API Key

Recommended
The Movie Database (TMDb) provides posters, backdrop fanart, plot summaries, and trending media content on your TV home screen.

How to get a free TMDb API Key:

  1. Create a free account or log in at themoviedb.org ↗.
  2. Go to your Account Settings > API ↗ page.
  3. Click Create and select Developer.
  4. Accept the terms and enter basic details (e.g. App Name: Resonance Launcher, Description: Personal TV Launcher).
  5. Copy your API Key (v3 auth) string and paste it below.

Streaming Availability API Key

Optional
Enables direct deep-linking into content inside your installed streaming apps (e.g. Netflix, Prime Video, Disney+, Apple TV+).

How to get a Streaming Availability API Key:

  1. Visit the Movie of the Night Developer Portal ↗.
  2. Sign up or log into your developer account.
  3. Generate or copy your Streaming Availability API Key.
  4. Paste your API key into the field below.
Changes will be instantly transmitted to Resonance Launcher on your TV network.
